ricdom examples

Six build-free demo pages. Each opens directly in a browser — no npm install, no bundler.

  • hello.html — the smallest possible app: one <script> tag and a counter (ricdom core only).
  • controls.html — every stateless control, layout, and text component (ricdom/ui, no app.use() needed).
  • ui.html — dialog, popup, toast, and tooltip (stateful components registered via app.use()).
  • composite.html — splitter, scroll pane, collapse box, accordion, tabs, dropdown, and the inline menu.
  • tweak.html — createTweakPanel, a dat.GUI-style parameter panel with live-updating output.
  • md-editor.html — ricdom/md-editor (opt-in subpath, its own IIFE): a real <textarea> with Markdown syntax colors.
